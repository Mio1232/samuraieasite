Step 02 — Install

導入方法

MT4 にsamurai EAを設置する手順です。画像のとおり進めれば5〜10分で完了します。うまくいかないときは各ステップの注意点と FAQ を確認してください。

準備するもの：①samurai EA ファイル（.ex4）　②取引口座のログイン情報　③MT4（PC版）。
▶ samurai EA をダウンロード（.ex4）

MT4をインストールしてログイン

XM / HFM の公式からプラットフォームをダウンロードし、口座番号・パスワード・サーバー名でログインします。

データフォルダを開く

MT4のメニュー「ファイル」→「データフォルダを開く」をクリック。エクスプローラーが開きます。

EAファイルをExpertsに入れる

MQL4→ Experts フォルダを開き、受け取ったEAファイルをコピーして貼り付けます。

プラットフォームを再起動

一度MT4を閉じて再起動します。左側の「ナビゲーター」→「エキスパートアドバイザ」にsamurai EAが表示されればOKです。

チャートを開いてEAを適用

指定の通貨ペア・時間足のチャートを開き、EAをチャート上にドラッグ＆ドロップします。

自動売買を許可してON

設定ウィンドウで「アルゴリズム取引を許可」にチェック。ツールバーの「自動売買」ボタンを押して緑にします。チャート右上のニコちゃんマークが笑顔なら稼働中です。

動かないときは：まず、口座番号の承認が済んでいるかご確認ください（samurai EA は許可された口座番号でのみ稼働します）。あわせて「自動売買」ボタンが緑か、EA設定で自動売買が許可されているか、通貨ペア・時間足が指定どおりかを確認してください。詳しくは FAQ をご覧ください。
